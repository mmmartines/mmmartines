## Projetos em destaque

### 🎬 Cinéfilo
Diário de cinema social completo — catálogo, avaliação emocional, listas
compartilháveis, gamificação por XP, chat em tempo real e recomendação por IA.
Distribuído em três repositórios:

- **[Cinefilo_app](https://github.com/mmmartines/Cinefilo_app)** — React Native / Expo, arquitetura DDD por features
- **[Cinefilo_server](https://github.com/mmmartines/Cinefilo_server)** — API serverless na Vercel, autenticação por JWT do Supabase
- **[Cinefilo_web](https://github.com/mmmartines/Cinefilo_web)** — React + TypeScript + Vite

Persistência poliglota: Supabase (PostgreSQL) para identidade, perfis e chat;
AstraDB (Cassandra) para dados append-only de alto volume.

### ⚙️ [processamento_lote](https://github.com/mmmartines/processamento_lote)
Processador de lote em C# para ingestão de milhões de registros com baixo consumo
de memória: streaming simultâneo de leitura e escrita, isolamento de falha por
linha e conformidade com a RFC 4180 no escape de CSV.

### 🌦️ [IFKlima](https://github.com/mmmartines/IFKlima_server)
Estação meteorológica ponta a ponta — firmware Arduino
([IFKlima_arduino](https://github.com/mmmartines/IFKlima_arduino)), servidor de
coleta em Java e frontend de visualização
([IFKlima_webapp](https://github.com/mmmartines/IFKlima_webapp)).
Onde começou meu trabalho com integração de dispositivos físicos.
